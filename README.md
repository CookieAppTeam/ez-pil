# Ez PIL

A fork of [easy-pil](https://github.com/shahriyardx/easy-pil), built on top of [PIL](https://github.com/python-pillow/Pillow) to easily edit/modify images.

## Getting StartedHere are some links to help you get started.

- Read the [docs](https://easy-pil.readthedocs.io/en/latest/)
- First steps [Introduction](https://easy-pil.readthedocs.io/en/latest/pages/intro.html)
- Integrate in a [Discord bot](https://easy-pil.readthedocs.io/en/latest/pages/discordbot.html)
- Some premade [Examples](https://github.com/CookieAppTeam/ez-pil/tree/master/examples)
